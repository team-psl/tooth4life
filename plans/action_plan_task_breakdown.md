# Action & Execution Task Breakdown: Tooth4Life Website Build

## Phase 1: Pre-Development Setup & Access Gathering (Day 0)
- [ ] **Asset Verification:** Confirm receipt of client text content, logo asset, image files, and final access to the 3 video files from Google Drive.
- [ ] **WordPress Environment Setup:** Initialize local/staging WordPress environment (clean WP install with latest stable build).
- [ ] **Server Compatibility Check:** Verify hosting environment PHP version (PHP 8.3/8.4 recommended, with memory limit set to at least 256M).

---

## Phase 2: Core Foundation & Plugin Installation (Day 1 - Morning)
- [ ] **Theme Installation:** Install and activate **Astra (Free)** or **GeneratePress (Free)** theme.
- [ ] **Plugin Installation:** Install and activate required plugins:
  - Elementor (Free)
  - Essential Addons for Elementor
  - Rank Math SEO
  - LiteSpeed Cache / WP Super Cache
  - Really Simple SSL
  - All-in-One WP Migration / Duplicator
- [ ] **Global Styling Setup:** Set base typography, primary brand colors, and logo according to `tooth4life.co.uk` branding guidelines.

---

## Phase 3: Page Building & Media Integration (Day 1 - Afternoon)
- [ ] **Page Hierarchy Creation:** Create up to 6 core pages (Home, Services, Video/Case Studies, About, Chamber Info/Contact).
- [ ] **Layout Construction:** Build clean grid layouts for each page using Elementor.
- [ ] **Video Embedding:** Integrate the 3 problem-solution videos into responsive media containers on dedicated sections/pages.
- [ ] **Image Asset Placement & Attribution:**
  - Place custom video frame images alongside respective context blocks.
  - Sourced supplemental free images added where necessary.
  - Add footer/legal image attribution credits for copyright compliance.
- [ ] **Direct Action Touchpoints:** Add mobile Click-to-Call (`tel:`) and WhatsApp click-to-chat links across header/footer and contact pages.

---

## Phase 4: Optimization, Testing & QA (Day 2 - Morning)
- [ ] **Mobile Responsiveness Check:** Audit layout across Mobile, Tablet, and Desktop breakpoints.
- [ ] **Basic SEO Configuration:** Set up meta titles, meta descriptions, and alt tags for images via Rank Math.
- [ ] **Performance & Caching:** Configure caching plugin, enable CSS/JS minification, and test load times.
- [ ] **Quality Assurance:** Verify all links, video embeds, image credits, and structural navigation flow.

---

## Phase 5: Client Review, Revision & Package Export (Day 2 - Afternoon)
- [ ] **Staging Review / Client Handover:** Deliver initial draft for client review (1 round of revisions).
- [ ] **Revision Implementation:** Execute requested adjustments based on client feedback.
- [ ] **Deployment Package Generation:** Export the complete WordPress site (files + database) as a single `.zip` / `.wpress` package.
- [ ] **Final Delivery:** Deliver zip archive to client along with hosting installation instructions.
